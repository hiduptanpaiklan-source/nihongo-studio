# Nihongo Studio — Unified Phase Interface

## What changed
- Phase F overview uses the same sidebar, header and card system as Phase E.
- Consistent logo, typography, navigation, backgrounds and breakpoints across all lesson and practice pages in both phases.
- Sidebar includes phase-specific modules, Homepage link and Switch Phase action.
- Added a shared CSS layer: `assets/unified-ui.css`.
- Included the approved number-audio fix (yon for 4, hachi for 8), including its page dependencies.
- Existing Phase E and Phase F lessons, translations, test data, quiz keys and score-storage IDs preserved.

## Deployment
Upload the **contents** of this release folder to the existing GitHub repository root, replacing same-name files. Keep the repository's existing `CNAME` file (and domain settings). Do not upload an extra enclosing folder.

## QA limitations
Code and browser-level testing are not a substitute for a native Japanese language review, real-device voice assessment, or a commercial security and legal audit.
