NIHONGO STUDIO — WEBSITE BELAJAR BAHASA JEPANG
================================================

CARA MEMBUKA
1. Ekstrak file ZIP sampai muncul folder "Nihongo-Studio".
2. Buka "index.html" dengan browser (Chrome, Edge, Safari, atau browser modern lainnya).
3. Gunakan menu untuk memilih materi dan latihan.

ISI WEBSITE
- Beranda: panduan belajar dan navigasi
- Angka Jepang: 60 angka (1–50.000)
- Salam & Perkenalan: salam, ungkapan, dialog
- Kosakata Dapur: peralatan, kata kerja, keselamatan, dialog
- Tata Bahasa: contoh kalimat, partikel dan perubahan bentuk kata kerja
- Latihan: 22 sesi x 10 soal = 220 soal

PENGUCAPAN / AUDIO
- Klik tombol pengeras suara di dekat tulisan Jepang. Ini juga berlaku
  untuk pertanyaan, pilihan jawaban, dan kosakata pada latihan.
- Tombol audio pada pilihan jawaban berbeda dengan tombol untuk memilih jawaban.
- Klik "Suara Jepang" di pojok kanan atas untuk memilih suara Jepang,
  mencoba cuplikan suara, dan mengatur kecepatan.
- Browser memprioritaskan suara Jepang berkualitas lebih natural jika tersedia.
  Kecepatan awal 1,00x agar ujaran tidak terdengar terlalu lambat.
- Suara yang dihasilkan adalah suara dari browser/perangkat (Web Speech API),
  BUKAN berkas MP3 hasil rekaman yang disertakan di folder ini.
- Fitur audio hanya dapat bekerja jika suara berbahasa Jepang tersedia di
  perangkat/browser. Pada beberapa perangkat suara natural membutuhkan internet.
  Jika tidak tersedia, browser akan menampilkan petunjuk untuk memasang suara.
- Untuk pengalaman yang lebih alami, coba Microsoft Edge dengan suara Jepang
  berkualitas tinggi jika tersedia, atau instal suara bahasa Jepang berkualitas
  tinggi melalui pengaturan bahasa/speech perangkat. Kualitas suara berbeda
  antarperangkat dan tidak bisa dijamin sama.

PROGRES BELAJAR
Nilai latihan dan tanda materi selesai disimpan melalui browser pada perangkat
ini. Penghapusan data browser dapat menghapus progres tersebut.

CATATAN
Materi dan kuis dapat diakses secara lokal tanpa server. Audio memerlukan
mesin pengucapan yang didukung oleh perangkat atau browser. Tidak diperlukan
akun untuk membuka halaman HTML.
